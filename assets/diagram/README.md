# Question diagrams

Place question diagrams in this folder.

Set the question's `question_image` field to either:

- `assets/diagram/example.png`
- `example.png` (looked up in this folder)

Absolute image paths and other paths relative to the application root remain supported for existing questions.

Use common image formats supported by Qt, such as PNG, JPEG, or WebP. Keep filenames stable once referenced by questions.
